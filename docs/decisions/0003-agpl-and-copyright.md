# 0003: AGPL-3.0, written from scratch, copyright held by the project

- **Status:** Accepted
- **Date:** 2026-11-01

## Decision

- RyProx is licensed AGPL-3.0-only.
- It is written from scratch under the [clean-room policy](../../CLEAN-ROOM.md). No code is copied from other projects, open source or otherwise.
- Contributions use DCO sign-off now. A Contributor Licence Agreement will be adopted before the first outside contribution is merged.

## Why

- **AGPL** means anyone running a modified RyProx as a service must share their changes. This stops a closed fork competing with the open project.
- **From scratch** means the project holds copyright in all its code, which keeps options open: for example, offering commercial licences to companies that can't use AGPL, to fund development.
- **No paywalled features.** If RyProx earns money, it will be from hosting, support and licences, never by locking features away.
